# Original asset provenance

- Robot and arena artwork is drawn from original geometric shapes by `src/render.js`. No imported character designs, sprite packs or earlier BattleBrotts assets are used.
- Mechanical sounds are original oscillator and envelope combinations in `src/audio.js`. No recorded samples, external audio libraries or music are used.
- Typography uses fonts already supplied by the visitor's device. No font files are downloaded or redistributed.
- `media/presentation-battle.png` is an actual unaccelerated Chromium gameplay screenshot of this project. It shows the Close Coil in the second encounter. Capture source was commit `c581c1f2d0565178cf545191d692d90b06284229`.
- `media/presentation-reward.png` is an actual earlier development screenshot of this project's first reward screen, before numerical before/after comparisons were added. It is labeled as development gameplay, not a final release screenshot. Replace it with the verified final capture before release.
